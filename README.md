# Кирилл Колесников - портфолио

Живой сайт: **https://realistiks.github.io/portfolio/**

Python-разработчик: автоматизация, компьютерное зрение, сети и игры на Godot.

## Проекты

- Автозакупка лотов на аукционе: YOLOv8, OCR и автоматизация интерфейса.
- Порт игрового макроса с Keyran на Python.
- Парсер цен FunPay.
- Zombie Waves - top-down шутер на Godot 4 для VK Mini Apps и Yandex Games.
- VPN Screener - массовая проверка прокси и VPN-конфигов по реальным сценариям.

## Структура

- `index.html` - весь сайт: стили и скрипты встроены.
- `img/` - скриншоты проектов и другие изображения.
- `img/zombie/trailer.mp4` - трейлер Zombie Waves.

Сайт статический: откройте `index.html` в браузере. Для публикации подходит любой static hosting, сейчас используется GitHub Pages.

## Безопасность

Скриншоты VPN Screener обезличены: адреса серверов, имена конфигов и ссылки подписок скрыты. Рабочие конфиги и списки в репозиторий не попадают.
